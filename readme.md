## About This Repository

This repository contains the complete MATLAB source code, output figures, and documentation for all laboratory sessions of the Computational Engineering course. Each session is self-contained in its own folder and can be run independently without any additional MATLAB toolboxes.

**MATLAB R2020a or later is recommended. No extra toolboxes required.**

## Lab Sessions Summary

| Session | Topic | Key Methods | Problems Solved |
|---|---|---|---|
| **Lab 01** | MATLAB Basics, Taylor Series & Numerical Errors | Maclaurin series, Euler method | sin(x) convergence, Falling parachutist, Quadratic equation |
| **Lab 02** | Bisection Method | Bisection | Parachutist drag coefficient, $f(x) = \sin 10x + \cos 3x$ |
| **Lab 03** | False Position Method | False Position (Regula Falsi) | $x^{10} - 1$, Rocket velocity, Floating sphere |
| **Lab 04** | Newton–Raphson & Fixed-Point Iteration | Newton–Raphson, Simple Fixed-Point Iteration (FPI) | Nonlinear spring-mass system (Energy balance) |
| **Lab 05** | Secant & Modified Secant Methods | Secant, Modified Secant | Projectile trajectory engineering problems (Launch angle matching) |
| **Lab 06** | Inverse Quadratic Interpolation Method | Inverse Quadratic Interpolation (IQI) | Catenary cable horizontal tension calculation ($T_A$) |
| **Lab 07** | Numerical Differentiation and Polar Motion | Finite-difference formulas ($O(h)$ and $O(h^2)$), Built-in `gradient` & `diff` | Polynomial derivatives error analysis, Polar radar-tracking data (Aircraft kinematics) |
| **Lab 08** | Trapezoidal Rule and Multiple Integrals | Single/Composite Trapezoidal Rule, Multiple (Nested) Integrals | Distance from velocity data, Double & Triple integration evaluation |
| **Lab 09** | Numerical Solution of Ordinary Differential Equations | Euler's Method, Midpoint Method, Predictor-Corrector (Heun's) Method | First-order IVP test problems ($\frac{dy}{dt} = y \sin t$) error-vs-h study |
| **Lab 10** | Runge-Kutta Method and Dynamical Systems | Classical 4th-Order Runge-Kutta (RK4), Bidirectional integration driver | Damped harmonic oscillator / Dynamical systems trajectories ($y(t) = e^{-0.1t}\cos(2t)$) |

## Topics Covered

- Numerical errors: truncation error, round-off error, absolute and relative error
- Taylor and Maclaurin series convergence
- Bracketing root-finding methods: Bisection, False Position
- Open root-finding methods: Fixed-Point Iteration, Newton–Raphson, Secant, Modified Secant
- Successive approximation via Inverse Quadratic Interpolation (IQI)
- Forward, backward, and centered finite differences for higher-order derivatives
- Numerical single and composite integration for equally/unequally spaced data
- Single-step ODE integration schemes (Euler, Midpoint, Heun)
- Multi-stage Runge-Kutta methods for state-space dynamical system simulations
- Engineering applications: ballistics trajectories, catenary cable design, velocity/acceleration profiling, and system dynamics
